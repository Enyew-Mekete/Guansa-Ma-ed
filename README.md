Guansa Ma'ed Restaurant Management System
A modern full-stack restaurant management platform built for Guansa Ma'ed (ጓንሳ ማዕድ) using React, Node.js, Express, and Neon PostgreSQL.

Overview
Guansa Ma'ed is a comprehensive restaurant website and management system designed to provide customers with an excellent online experience while giving administrators powerful tools to manage restaurant operations.

Installation
Clone Repository
git clone https://github.com/YOUR_USERNAME/guansa-maed.git
cd guansa-maed
Install Dependencies
npm install
Environment Variables
Create a .env file:

DATABASE_URL=your_neon_database_url
JWT_SECRET=your_jwt_secret
EMAIL_USER=your_email
EMAIL_PASS=your_email_password
Run Development Server
npm run dev
Build Project
npm run build
Deployment
Frontend
Deploy on Vercel:

vercel
Backend
